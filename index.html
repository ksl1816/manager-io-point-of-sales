This is a Manager.io Extension

You're viewing this page directly in a browser — it only works when installed inside Manager.io. Follow the steps below to add it.

1
Open Manager.io
Open your business, go to the Settings tab, and select Extensions (on newer versions there's also a top-level Extensions icon in the main navigation).
2
Click "New Extension"
This opens a form for adding a custom extension.
3
Fill in the details
Name: POS Terminal (or anything recognizable)
Endpoint: the link below — copy it exactly
4
Set the Placement
Manager will show a dropdown of valid pages (e.g. Sales Invoices or a Point of Sale area) — pick wherever you want this terminal's iframe to appear, then Save.
5
Create a free account
Once it loads inside Manager, you'll see a sign-up screen — create a free account (or log in if you already have one) to unlock the terminal. No approval needed, it's instant.

Default POS Customer
Walk-in sales are posted against a customer with code 999 or named "POS". If your business doesn't have one yet, create it here.
Walk-in Custom Fields (optional)
By default the walk-in Name/Phone are saved as plain text in the invoice description. If you'd rather have them as proper, filterable fields on the Sales Invoice, create these two Text Custom Fields yourself in Manager — it only takes a minute:
1
Go to Settings → Custom Fields → New Text Custom Field
2
Name it Customer Name, and under Position on documents tick Sales Invoice, then Save
3
Repeat, naming the second one Customer Phone, also placed on Sales Invoice
Once both exist, come back and click Refresh below — the POS will detect them automatically and this checklist will confirm it.
